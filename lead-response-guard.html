A focused first project

Choose one intake channel and one response threshold. We map how a Lead enters Salesforce, who owns it, what counts as a first response, and how to report exceptions. A customer-approved implementation can add monitoring, an Agentforce action and a dashboard.

What the first version measures

  • Leads older than a configured threshold.
  • No activity logged in Salesforce for the Lead.
  • A review recommendation, with no automatic message to the customer.

Salesforce activity dates do not capture every phone call or contact outside the CRM. Production SLA reporting needs an agreed, auditable event definition.

Where Agentforce fits

Deterministic action

An Apex invocable action can check one or more authorized Lead IDs in user mode and return a short explanation. The source prototype is prepared for Salesforce org validation.

Controlled agent experience

For staff who have access, an Agentforce action can present the result and guide a human review. An agent template and managed package must be built and tested in an eligible Salesforce org before marketplace distribution.

Security boundaries: least-privilege access; no names, phone numbers or customer notes in the action result; no autonomous outreach. The website demo uses invented inputs only.
